# 매입 미입력 현장을 마진 100%로 보이지 않게

- **시작일**: 2026-11-01
- **BACKLOG 항목**: 위임 지시 (과거 견적 적재 후 대시보드 손익 오해 방지)
- **예상 규모**: S
- **상태**: DONE

## 목표
매입이 0원인 현장이 대시보드·현장 화면에서 마진율 100%, '흑자', '양호'로 보이지 않게 한다. 평균 마진율·흑자 판정은 매입이 입력된 현장만으로 계산하고, 계산 기준을 카드에 짧게 적는다.

## 배경 / 동기
과거 견적만 적재되고 매입이 아직 없는 현장이 대부분이라, 견적액이 그대로 마진으로 잡혀 '평균 마진율 100.0% 양호'처럼 실제 손익으로 오해된다. 매입 미입력과 실제 100% 마진을 구분할 표시가 없었다.

## 접근법
- 백엔드 DTO는 바꾸지 않는다. `GET /api/v1/dashboard/stats`의 `siteProfits`가 보관 제외 전체 현장의 견적액·매입액을 이미 주므로 프론트에서 다시 집계한다.
- 순수 함수 `frontend/src/utils/marginEvaluation.ts`
  - `hasPurchaseInput`: 매입 1원 이상이면 입력됨
  - `evaluateMargin`: 서버 합계처럼 수주 전(BIDDING)을 빼고, 견적·매입이 모두 1원 이상인 현장만 견적 가중 평균(마진 합 / 견적 합)
  - `siteMarginRateCaption`: 현장 단위 카드 보조 문구
- 대시보드
  - 총 매출·총 매입 카드는 서버 값 그대로
  - 총 마진·평균 마진율 카드는 판정 대상 현장 기준 값과 흑자/적자·양호/주의, 보조 문구 "매입 입력된 N개 현장 기준"
  - 판정 대상이 없으면 값 `-`, 배지 없음, 보조 문구 "매입 입력 후 계산"
  - 현장별 손익 표: 매입 0원 현장은 마진율 대신 회색 '매입 미입력' 태그, 마진 금액은 회색
- 현장 상세·현장 목록 마진 카드: 매입 0원이면 "매입 미입력 · 매입 입력 후 계산", 색상 회색
- MSW 대시보드 핸들러에 매입 0원 현장 1곳을 둬 목업에서도 태그가 보이게 함

## 리스크 / 모르는 것
- 프론트 재계산 값은 서버 `totalMargin`·`averageMarginRate`와 다르다(서버는 매입 0원 현장 포함). AI 요약(서버 생성)의 마진율 문구는 여전히 서버 기준이라 대시보드 카드와 다를 수 있다. 서버 기준 자체를 바꾸려면 site-service `DashboardService`/`DashboardSummaryFacts` 변경이 필요 — 이번 범위 밖, 보고만.
- 견적 0원·매입만 있는 현장은 마진율이 정의되지 않아 판정에서 뺐다(서버 AI 요약의 '견적 미등록' 처리와 같은 취지).
