# 내역서형 견적 양식 해석

- **시작일**: 2026-11-01
- **BACKLOG 항목**: 로컬 실데이터 견적 적재(USB) — 보류 파일 해소의 일부
- **예상 규모**: M
- **상태**: DONE

## 목표
`scripts/import/estimate_sheet.py`가 '견적서' 양식 외에 '내역서형' 양식(재료비·노무비·합계 묶음별 단가·금액)을 감지해 품목·합계를 읽도록 한다. 확신할 수 없는 행·합계는 ERROR로 남긴다.

## 배경 / 동기
보류된 실데이터 일부가 내역서형 양식이라 고정 위치(R11C7 합계금액, R6C6 현장명)와 단일 단가·금액 열로 읽으면 "품명 없이 금액/단가가 있음", "품목 합계 ≠ 합계금액 셀" ERROR가 나고, 머리글 글자를 현장명으로 잘못 읽는 경우도 있었다.

## 접근법
- 감지: 품명/명칭/DESCRIPTION 머리글 행부터 3행 안에 `단가`·`금액`이 각각 2번 이상 → 내역서형. 가장 오른쪽 단가·금액(합계 묶음)을 쓴다. 기존 견적서 양식(단가·금액 1번)은 그대로 기존 경로.
- 열 매핑: 품명·규격·단위·수량·번호(구분)·비고를 머리글 글자로 찾는다. 품명 칸이 비면 규격을 품명으로, 둘 다 있으면 `품명 (규격)`.
- 제외: 머리글 왼쪽 열의 `*` 공종 표시 행, `<...>`·`■` 구역 제목, 소계·합계 행.
- 합계: `합계금액`(총합계 등) 행 → 없으면 마지막 `합계` 행 금액을 합계로 쓰고 출처 경고. 합계 행 뒤 금액 행(공과잡비 등)은 최종 합계금액 행이 뒤에 있을 때만 1식 품목으로 넣고 품목 합계로 검증.
- 금액 0 또는 단가만 있는 미기재 행은 "금액 없는 품명 행"으로 제외.
- 수신처·현장명 칸이 없으므로 비워 두고 `--site-from-folder`에 맡긴다.
- 품목 생성 꼬리 로직은 `_build_item`/`_finish`로 분리해 두 양식이 공유(기존 동작 불변).

- 단가·금액 묶음이 2개 이상인 견적서 양식이 있으면 내역서형으로 읽혀 수신처·현장명 고정 칸을 쓰지 않게 된다. 이번 보류 목록의 견적서 양식 파일은 결과가 바뀌지 않음을 확인했다.
