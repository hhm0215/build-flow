## 목표

BuildFlow 저장소에서 에이전트가 작업별 PR 생성 적합성·커밋 범위를 검토하고, 커밋·push·PR 생성·CI·SHA 검증·merge·후처리까지 자율적으로 수행한다. 매 작업의 건별 사용자 확인은 받지 않되 안전망은 유지한다.

## 접근법

1. 사용자 위임 범위를 이 저장소의 `develop`→`main` 워크플로우로 한정한다. force·main 직접 push·검증 우회는 계속 금지한다.
2. CLAUDE/자동화 가이드/ADR의 상충된 승인 문구를 정렬한다. 작업별 계획과 커밋 목록은 에이전트가 자체 검토·기록하고, PR 생성 전에 독립 코드 리뷰와 CI 준비를 확인한다.
3. 현재 거래처 등록 작업과 앞선 로컬 커밋을 검토·커밋·push하고, PR 실제 커밋 SHA와 `origin/main..origin/develop` SHA가 완전히 일치할 때만 merge한다.
4. merge 후 Git 상태·PROGRESS를 갱신하고 BACKLOG 최우선 작업을 이어간다.
