# 인증 API 비지원 메서드 405

## 배경·범위

공개 테스트 파일럿에서 `GET /api/v1/auth/login`이 500으로 응답했다. 실제 로그인은 POST만 지원한다. 전역 catch-all이 Spring MVC의 메서드 불일치를 내부 오류로 처리하므로 auth-service에서 405로 교정한다. VPS 배포와 인증 자격 증명 사용은 이번 코드 변경 범위 밖이다.

## 구현·검증

- `HttpRequestMethodNotSupportedException`을 catch-all보다 구체적으로 처리해 HTTP 405, `Allow` 헤더와 기존 `ApiResponse` 오류 형식을 반환한다. 요청 본문·계정 정보·스택트레이스를 로그에 쓰지 않는다.
- standalone MVC 회귀에서 GET `/login`의 405/Allow/응답과 AuthService 미호출을 검증한다.
- `:auth-service:test` 및 CI를 통과하고 보안 역할의 독립 검토를 받는다.
- 실제 공개 HTTPS 응답은 새 버전 배포 전까지 기존 500일 수 있다. 배포 게이트를 통과한 뒤 재실측한다.
