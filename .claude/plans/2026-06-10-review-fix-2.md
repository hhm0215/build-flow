## 배경 / 동기

- Fix 1: axios가 `FormData`를 입력으로 받을 때 `Content-Type: multipart/form-data; boundary=...`를 자동 설정한다. 수동으로 `'multipart/form-data'`만 박으면 **boundary가 누락**되어 서버가 파싱 못하는 경우 발생 가능. 현재는 동작하지만 잠재적 버그.
- Fix 2: parse 실패 시 무조건 generic 메시지("공내역서 파싱에 실패했습니다.")만 보여줌. 백엔드가 어떤 이유로 실패했는지(파일 포맷 / Ollama 응답 형식 깨짐 / timeout 등) 사용자·디버거 양쪽에 안 보임.

```diff
+ import { isAxiosError } from 'axios'
...
- onError: () => {
-   message.error('공내역서 파싱에 실패했습니다. 다시 시도해 주세요.')
- },
+ onError: (error) => {
+   const backendMsg = isAxiosError(error)

+ },
```

`any` 캐스트 없이 타입 안전. ESLint v9 max-warnings:0 통과 목표.
