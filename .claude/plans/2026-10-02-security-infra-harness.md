# 공개 전 보안·인프라 점검 하네스

- **시작일**: 2026-10-02
- **연결 작업**: VPS 외부 HTTPS 테스트 접속 및 반복 운영 점검
- **상태**: IN_PROGRESS

## 목표

공개 HTTPS 파일럿의 사전 게이트를 실측하고, 보안·인프라 독립 역할과 반복 점검 절차를 저장소 지침에 고정한다. 실제 업무 데이터 입력/운영 자동 배포는 별도 게이트로 유지한다.

## 범위와 계획

1. 저장소·VPS private 기준선을 읽기 전용으로 확인하고 독립 보안/인프라 리뷰를 수렴한다.
2. 실패/미검증/통과를 구분한 `docs/SECURITY_OPERATIONS.md`와 역할별 지침을 `AGENTS.md`/`CLAUDE.md`에 연결한다.
3. 공개 Compose 검증 우회와 UI 로그아웃 토큰 폐기 결함을 수정하고 회귀 테스트·CI를 통과시킨다.
4. 일정 기반 읽기 전용 점검을 등록한다. 변화 없으면 조용히, 장애/중대한 변화만 알린다. 서버 변경·재배포는 자동화하지 않는다.
5. 수정 릴리스가 `main`에 병합되고 VPS에 반영된 후에만 공인 TLS·실제 401/429/CORS·포트 검증으로 공개 여부를 판정한다.

## 확인된 이슈

- UI 로그아웃이 서버 `/auth/logout`을 호출하지 않아 기존 access token 폐기 검증 불가 — 공개 전 수정.
- SSH root/password 허용, 보류 중인 커널 업데이트 — 복구 경로를 확인한 후 별도 하드닝/재부팅 검증 필요.
- 외부 백업/격리 복원, DB 최소 권한/Flyway, 실제 재부팅·CRUD/PDF 검증은 실데이터 운영 선행조건.
- Compose 정적 검증은 외부 접근 검증이 아니며, 기존 검증기에서 host networking 등 우회 가능성을 보강.

## 완료 판정

- 역할 지침과 체크리스트가 저장소에 반영되고 테스트 통과.
- 정기 보안/인프라 점검 등록과 실제 실행 가능성 확인.
- 실패 게이트가 `PASS`로 바뀌기 전 공개 포트를 열지 않음.

## 결과

독립 보안·인프라 리뷰를 수렴해 체크리스트·역할 지침을 반영했다. 로그아웃 UI 수정과 Compose 검증기 강화에 대해 로컬 프론트 lint/34파일 118테스트/프로덕션 빌드, Python 11테스트, 4파일 Compose 병합 검증, `git diff --check`를 통과했다. Codex 앱에 매일 보안/인프라 점검 heartbeat 두 건을 등록했다. PR #69의 CI 8개와 SHA 검증 후 main merge `5a372f2`, develop fast-forward를 마쳤다. VPS도 해당 SHA로 고정해 frontend만 재빌드·기동했으며 private 15개/200/401/SSH 22만 확인했다. 실제 토큰 폐기 재사용·공인 TLS/429/CORS는 아직 미실측이다. SSH 하드닝은 안전 검토 거부로 승인을 요청했고, 커널 패치·외부 백업/복원은 별도 게이트로 남긴다.
